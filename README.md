# Paromita Bordoloi — Academic Website

A minimalist, elegant academic homepage for GitHub Pages.

## Publish it

1. Create a public GitHub repository named `YOURUSERNAME.github.io`.
2. Upload `index.html`.
3. Upload your CV as `cv.pdf`.
4. Replace `YOUR-EMAIL@example.com` with your email.
5. Replace the Google Scholar, ORCID and arXiv placeholder links.
6. Replace the photograph placeholder with your photo if desired.
7. Go to **Settings → Pages** in the repository.
8. Under **Build and deployment**, select **Deploy from a branch**, choose `main`, and save.

Your site will then appear at:

`https://YOURUSERNAME.github.io/`

## Photo

The current design uses a decorative placeholder. To add a real photo, you can replace the
`.photo` div with an image such as:

```html
<img class="photo" src="photo.jpg" alt="Paromita Bordoloi">
```

and upload `photo.jpg` to the repository.
